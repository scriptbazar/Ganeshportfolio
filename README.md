## ✨ Flagship Key Features

- ⚡ **Sub-Second Edge Execution & 100/100 Web Vitals**: Optimized asset rendering, sub-0.1s page load times, and GPU-accelerated 120 FPS glassmorphic UI.
- 👾 **BUG BLASTER 2026 // Developer Arcade Game**: An interactive HTML5 Canvas arcade game with hit particle physics, combo multipliers (`2X`, `3X`, `4X`), dynamic target spawning (`👾 Bug`, `🐞 Crash`, `⚡ Power-Up`), and persistent high scores.
- 💻 **Interactive Terminal Widget v2.0**: Multi-file tab editor (`developer.js`, `experience.json`, `contact.config`) with live `▶ RUN CODE` compilation logs and 1-click clipboard copying.
- 📊 **Real-Time GitHub REST API Sync**: Asynchronously syncs live public repositories, star counts, primary languages, member duration, and GitHub activity heatmaps (`@scriptbazar`).
- 📄 **Universal Resume Downloader**: Direct 1-click text/PDF resume downloader attached to all hero, header, and floating dock action triggers, paired with an executive skill matrix preview modal.
- 📱 **Progressive Web App (PWA)**: Full offline support (`sw.js` Service Worker) with `NetworkFirst` caching and `manifest.json` for 1-click mobile & desktop app installation.
- 🎯 **Google JSON-LD Rich Snippet Schema**: Injected Person & SoftwareEngineer structured data for instant Google Search Knowledge Panel indexing.
- 🎨 **Ultra-Thin Neon Hairline Scrollbar**: 2px hairline scrollbar with hidden browser scrollbar arrow buttons across desktop and mobile.

## 🚀 Quick Start & Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) (v16.0.0 or higher)

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/scriptbazar/Ganeshportfolio.git
   cd Ganeshportfolio
   ```

2. **Install dependencies** (if required):
   ```bash
   npm install
   ```

3. **Launch local dev server**:
   ```bash
   npm start
   # or
   node server.js
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000`
